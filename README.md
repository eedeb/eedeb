## 🚀 Featured Projects

### 🦅 [FreeClaw](https://freeclaw.eedeb.dev/) — *active project*
A token-efficient AI agent with a web UI. It classifies intent locally with Classy-AI before any API call — routing to the cheapest capable model, trimming context windows, and running tools like web search, bash, file creation, and smart home control.

- Costs almost nothing per day to run
- Local intent routing before hitting a paid API
- Tool execution: search, bash, files, smart home

![Commit activity](https://img.shields.io/github/commit-activity/t/eedeb/FreeClaw)

---

### 🔹 [Classy](https://github.com/eedeb/Classy)
A lightweight neural network classifier that routes natural language queries to the right model, API, or system utility. The brain behind both Chat314 and FreeClaw's intent routing.

- Lightweight NLP classification engine
- Plug-and-play design with flexible API integration
- Core utility behind all my AI tools

![Commit activity](https://img.shields.io/github/commit-activity/t/eedeb/Classy)

---

### 🔹 [Chat314](https://app.chat314.com)
A browser-based AI chat platform powered by Classy. It intelligently selects the right AI or search tool per message — language, image generation, web search, system commands, and more.

- Responsive, minimal UI
- Connects to custom models and services

---

### 🔹 [Jimbot](https://github.com/eedeb/Jimbot)
A voice-activated Linux assistant that automates applications and system functions using AI-based classification.

- Wake-word detection via Porcupine
- Full system-level command execution
- Designed for Raspberry Pi and small Linux devices
